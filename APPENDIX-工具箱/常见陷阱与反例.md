# 常见陷阱与反例

> 数学直觉在机器学习里会失效的场景。这些"反直觉"案例，每个都对应一个真实工程陷阱。

## 陷阱 1：梯度下降找的不一定是全局最小

**直觉陷阱**：认为训练就是"找最低点"。

**真相**：神经网络损失**非凸**，有大量局部极小、鞍点、平坦区。在适当光滑性和步长等条件下通常只能保证某种驻点收敛；局部极小本身也不保证，更不保证全局最优。

**反例**：$f(x)=x^4-3x^2+1$ 在 $x=0$ 梯度为零，精确从这里开始的梯度下降停在局部最大点；而 $x=\pm\sqrt{1.5}$ 的函数值更小。两边的极小点都是全局极小，不能用它们作为“不同局部极小值”的反例。

**工程对策**：多次随机初始化、动量、模拟退火。

## 陷阱 2：ReLU 网络的"死亡神经元"

**直觉陷阱**：ReLU 简单好用，越大越好。

**真相**：若某神经元长期输入负区，梯度恒为 0，该神经元可能长期不更新；上游特征、其他样本或动量改变后也可能重新激活。

```python
# ReLU' = 0 当 x < 0 ⇒ 梯度阻断
# 若所有训练样本长期落在负区且没有其他更新机制，该神经元可能长期不更新
```

**工程对策**：Leaky ReLU、He 初始化、降低学习率。

## 陷阱 3：用 MSE 做分类

**直觉陷阱**：损失函数都差不多，随便选。

**真相**：MSE + sigmoid 在错得离谱处梯度**消失**（$\sigma'$ 饱和）。错得越狠学得越慢。

**数学**：$\frac{\partial}{\partial z}(\hat y - y)^2 = 2(\hat y-y)\sigma'(z)$，$\hat y \to 0/1$ 时 $\sigma' \to 0$。

**工程对策**：多数分类训练优先用 logits 交叉熵；MSE/Brier score 仍是合法选择，应理解梯度差异。

## 陷阱 4：softmax 数值爆炸

**直觉陷阱**：$\frac{e^{z_i}}{\sum e^{z_k}}$ 数学上没问题。

**真相**：$z_i = 1000$ 时 $e^{1000}$ 远超 float32 上限（$\sim 10^{38}$），变 `inf`。

**工程对策**：减最大值 $m = \max z$，数学等价数值稳定：

$$\frac{e^{z_i - m}}{\sum e^{z_k - m}}$$

PyTorch 的 `F.cross_entropy` 内部已做。

> 📖 [01-数值稳定性](../PART-04-从理论到工程/01-数值稳定性.md)

## 陷阱 5：忘记 train()/eval()

**直觉陷阱**：模型推理就是 `model(x)`。

**真相**：BatchNorm 在 train 模式用 batch 统计，eval 模式用移动平均。Dropout 在 train 启用 eval 关闭。**忘记切换会导致验证结果错误或不稳定**。

```python
model.train()  # 训练前
model.eval()   # 验证/推理前
```

## 陷阱 6：过拟合 ≠ 训练损失还能降

**直觉陷阱**：训练损失下降说明在学好。

**真相**：训练损失降但验证损失升 = **过拟合**。模型在背训练集，没学到泛化。

**诊断**：画训练/验证损失曲线。持续分叉是过拟合线索，还需排除验证噪声、分布偏移及 train/eval 设置差异。

**工程对策**：早停、正则、数据增强、Dropout。

> 📖 [04-正则化](../PART-02-深度学习核心/04-正则化.md)

## 陷阱 7：维度不匹配的静默广播

**直觉陷阱**：PyTorch 会自动处理维度。

**真相**：广播规则可能**静默**产生错误结果。

```python
a = torch.randn(3, 4)
b = torch.randn(4,)
c = a + b        # (3,4)+(4,)→(3,4) ✓ 正确广播
u = torch.randn(3, 1)
v = torch.randn(1, 4)
e = u + v        # (3,1)+(1,4)→(3,4)：静默成功，两个维度被"意外配对"成外积式相加
x = torch.randn(N)
y = torch.randn(N, 1)
z = x + y        # (N,)+(N,1)→(N,N)：一行代码悄悄放大 N 倍内存
```

**工程对策**：用 `assert x.shape == expected` 显式检查。

## 陷阱 8：梯度累加不清零

**直觉陷阱**：每个 batch 梯度自动重置。

**真相**：PyTorch 默认**累加**梯度。不清零会让梯度跨 batch 累积。

```python
opt.zero_grad()  # 每次独立更新前调用；有意累积 micro-batch 时在累积组开始清零
loss.backward()
opt.step()
```

## 陷阱 9：小 batch 的 BatchNorm 失效

**直觉陷阱**：BN 稳定训练，越大越有用。

**真相**：有效归一化样本太少时统计可能不稳；BN2d 还聚合空间维，因此 batch=1 不一定失败，batch=2 也不必然有害。二维输入 (1,C) 的训练 BN 则会因每通道仅一个值而报错。

**工程对策**：小 batch 用 GroupNorm/LayerNorm（不依赖 batch 维度）。

## 陷阱 10：相关 ≠ 因果

**直觉陷阱**：模型学到的相关性 = 真实因果。

**真相**：仅凭观察数据拟合预测关系，不能自动识别因果；神经网络也可用于带结构或干预假设的因果模型。典型混杂例子是气温同时影响冰淇淋销量与溺水人数，不能从二者相关推出销量导致溺水。

**后果**：分布偏移时（训练 vs 真实世界）泛化崩塌。

**工程对策**：领域随机化、对抗训练、因果建模。

---

## 陷阱 11：评估数据泄漏

**直觉陷阱**：训练-验证-测试三划分够了。

**真相**：若同一对象的不同视图分散在训练集和验证集（如同一患者的多次就诊），验证集**不独立**，指标虚高。

**工程对策**：按**组**划分（group split），而非随机。

---

## 陷阱 12：deep 网络不一定好

**直觉陷阱**：越深越强。

**真相**：
- 太深 + 无残差 ⇒ 梯度消失，训不动
- 太深 + 过参数 + 少数据 ⇒ 严重过拟合

**工程对策**：用验证集选深度，配残差 + 正则。

## 陷阱 13：学习率太大/太小的症状相似

**直觉陷阱**：损失不降就是学习率太小。

**真相**：学习率太大（发散震荡）和太小（龟速）都可能表现为"损失不降"。

**诊断**：
- 梯度范数大 + 损失震荡 ⇒ 学习率太大
- 梯度范数正常 + 损失平 ⇒ 学习率太小

**工程对策**：学习率范围扫描（lr finder）。

> 📖 [03-优化算法](../PART-02-深度学习核心/03-优化算法.md)

---

## 陷阱 14：Universal Approximation ≠ 能学到

**直觉陷阱**：通用近似定理说神经网络万能。

**真相**：定理在激活、函数空间及误差范数等条件下保证存在逼近，例如连续非多项式激活的宽网络可一致逼近紧集上的连续函数，**不保证梯度下降能找到**这组参数。所需宽度可能大到不可行。

**工程含义**：不能因为"理论上能"就忽视优化难度、数据量、正则。

## 陷阱 15：迁移学习的负迁移

**直觉陷阱**：预训练总是有益的。

**真相**：源任务与目标任务差异大时，预训练权重可能**阻碍**学习（负迁移）。

**诊断**：从头训练 vs 微调，对比验证损失。

**工程对策**：选择性解冻层、降低预训练学习率。
