# 正则化

> 正则化是在优化目标里**主动加一个"惩罚项"**，让模型宁愿简单也不要过拟合：$\tilde L = L + \lambda \Omega(\theta)$。数学上，这是在**拟合能力**与**复杂度**之间做权衡——本质是 Hilbert 空间里的**Tikhonov 正则化**或 Sobolev 空间里的**范数约束**。

**难度**：[标准]（需要偏差-方差分解 + 范数 + 一点泛函直觉）

## 一、纯数学版：为什么要惩罚复杂度

### 1.1 过拟合 = 经验风险最小化的病态

给定数据 $(x_i, y_i)_{i=1}^N$，朴素的训练目标是**经验风险最小化**：

$$\hat\theta = \arg\min_\theta \frac{1}{N}\sum_{i=1}^N \ell(f_\theta(x_i), y_i)$$

**问题**：高容量模型可能拟合训练噪声，训练误差低并不保证泛化好。不过插值解也可能良好泛化，是否过拟合需独立验证集判断。

### 1.2 正则化：结构风险最小化

加一个**复杂度惩罚** $\Omega(\theta)$：

$$\hat\theta = \arg\min_\theta \underbrace{\frac{1}{N}\sum \ell(f_\theta(x_i), y_i)}_{\text{拟合}} + \lambda \underbrace{\Omega(\theta)}_{\text{复杂度}}$$

$\lambda$ 控制"多在乎简单"。这是 Vapnik 的**结构风险最小化**原则。

### 1.3 偏差-方差分解的视角

对平方损失，期望泛化误差可分解为：

固定输入 $x$，设 $y=f_*(x)+\varepsilon$，$\mathbb E[\varepsilon\mid x]=0$、方差为 $\sigma^2$；训练集 $D$ 与测试噪声独立，则

$$\mathbb{E}_{D,\varepsilon}[(y - \hat f_D(x))^2] = \underbrace{(\mathbb{E}_D\hat f_D(x) - f_*(x))^2}_{\text{偏差}^2} + \underbrace{\mathbb{E}_D[(\hat f_D(x) - \mathbb{E}_D\hat f_D(x))^2]}_{\text{方差}} + \sigma^2.$$

- 过拟合 = 低偏差、高方差
- 欠拟合 = 高偏差、低方差
- 正则化 = 牺牲一点偏差，换方差大幅下降

> 📖 偏差-方差：[数理统计基础详解](https://github.com/CacinieP/Mathematics-Universe/blob/main/05-概率论与数理统计/06-数理统计基础/数理统计基础详解.md)

### 1.4 L2 正则 = Tikhonov = 高斯先验

取 $\Omega(\theta) = \|\theta\|_2^2$，目标变成：

$$\tilde L = L(\theta) + \lambda \|\theta\|_2^2$$

**三种等价视角**：
1. **优化**：惩罚大权重，让解"光滑"
2. **约束**：若惩罚问题取得全局最优解 $\theta_\lambda$，它也解半径 $R=\|\theta_\lambda\|_2$ 的约束问题。反向从任意约束半径找到等价乘数通常需凸性与适当约束资格；非凸神经网络不能无条件双向等同。
3. **贝叶斯**：若 $L=N^{-1}\sum_i(y_i-f_\theta(x_i))^2$、高斯观测噪声方差为 $\sigma^2$，高斯先验 $\theta\sim\mathcal N(0,\tau^2 I)$ 的 MAP 目标对应 $\lambda=\sigma^2/(N\tau^2)$。

若 $L$ 定义为平均负对数似然而非 MSE，则对应 $\tau^2=1/(2N\lambda)$；必须先固定损失的归一化，不能通用地省略这些常数。

### 1.5 L1 正则 = 稀疏 = 拉普拉斯先验

取 $\Omega(\theta) = \|\theta\|_1 = \sum_j |\theta_j|$：

$$\tilde L = L(\theta) + \lambda \|\theta\|_1$$

**几何**：L1 球有尖角，与等高线相切处常落在坐标轴上——使很多 $\theta_j = 0$，产生**稀疏解**。

**贝叶斯视角**：对应独立拉普拉斯先验。在上面的平均 MSE 约定下，尺度 $b=2\sigma^2/(N\lambda)$；若采用平均负对数似然，则 $b=1/(N\lambda)$。

## 二、应用映射层：从数学到深度学习的各种正则

### 2.1 权重衰减（Weight Decay）

普通 SGD 下，L2 正则可表现为权重衰减；自适应优化器下需区分耦合 L2 与解耦衰减。L2 惩罚的梯度为：

$$\nabla \tilde L = \nabla L + 2\lambda \theta$$

更新时多了一项 $-2\eta\lambda\theta$——每次把权重**往原点拉**一点。

### 2.2 Dropout（2012）

训练时随机**置零**一部分神经元（概率 $p$）：

$$h_{\text{drop}} = \frac{m}{1-p} \odot h, \quad m_j \sim \text{Bernoulli}(1-p)$$

**数学解释**：
- **集成视角**：随机训练共享参数的子网络；普通 eval 前向是近似集成，通常不等于所有非线性子网络输出的精确平均
- **贝叶斯视角**（Gal & Ghahramani, 2016）：在特定变分族与正则化假设下可解释为近似贝叶斯推断；MC Dropout 可估计预测波动，但不保证校准准确
- **正则视角**：禁止神经元过度依赖个别特征，强迫冗余表示

### 2.3 早停（Early Stopping）

验证集长期不再改善时停训，并恢复最佳检查点。在线性模型的二次损失下，早停与 L2 都能抑制某些谱方向，但它们的收缩因子不同，一般不存在统一的一一对应；深度网络中更不能声称严格等价。

### 2.4 Batch Normalization（附带正则效果）

原本为解决内部协变量偏移，实践发现其随机性（mini-batch 统计）有轻微正则作用。

### 2.5 数据增强

对输入做随机变换（翻转、裁剪、加噪）。**目标**：通过保持标签含义的变换表达任务不变性，并可能改善泛化。它通常不是严格的参数先验或 MAP 等价形式；会改变标签语义的增强反而可能有害。

## 三、L1 vs L2 的几何直觉

### 3.1 等高线与约束区域的相切

```
      L2 (圆滑)              L1 (菱形, 有尖角)
       ┌─────┐                  ◇
      /  •   \                ╱ │ ╲     等高线与尖角
     |  •切点 |               │ •┊•│    相切于轴上 ⇒ θ_j=0
      \       /                ╲ │ ╱     ⇒ 稀疏解
       └─────┘                  ◇
    (切点通常不在轴上)        (切点常落在尖角=坐标轴)
```

**结论**：L1 产生稀疏（特征选择），L2 产生小而分散的权重。

### 3.2 Elastic Net = L1 + L2

$$\Omega(\theta) = \alpha \|\theta\|_1 + (1-\alpha)\|\theta\|_2^2$$

兼顾稀疏性与稳定性，常见于高维稀疏数据。

## 四、工程实现层：PyTorch 正则化

### 4.1 权重衰减（最简单）

```python
# 直接在 optimizer 里指定 weight_decay
opt = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)
# 默认耦合 L2: grad += weight_decay·θ；对应惩罚 (weight_decay/2)‖θ‖²。
# 因而相对于上文 L+λ‖θ‖²，weight_decay=2λ，而不是 λ。
```

> ⚠️ **Adam 的 weight_decay ≠ AdamW**：Adam 的 weight_decay 把 $\lambda\theta$ 加进梯度，属于**耦合 L2**——会被自适应步长缩放，每个参数的等效衰减强度不同；AdamW 用**解耦权重衰减**（$\theta \leftarrow \theta - \eta\lambda\theta$，在自适应更新之外单独执行）。在自适应优化器下两者不等价（Loshchilov & Hutter 2019），实践中推荐 AdamW。

### 4.2 Dropout

```python
import torch
import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.drop = nn.Dropout(p=0.5)   # 训练时 50% 置零, 测试时自动关闭
        self.fc2 = nn.Linear(256, 10)
    def forward(self, x):
        x = self.drop(torch.relu(self.fc1(x)))
        return self.fc2(x)
# model.train() 启用 dropout; PyTorch 是 inverted dropout: 1/(1-p) 缩放在训练期前向中完成; eval() 恒等直通、不做缩放
```

### 4.3 早停

```python
best_val = float('inf')
patience, bad = 5, 0
for epoch in range(100):
    train_loss = train_one_epoch()
    val_loss = validate()
    if val_loss < best_val:
        best_val = val_loss; bad = 0
        torch.save(model.state_dict(), 'best.pt')
    else:
        bad += 1
        if bad >= patience:
            print("Early stop at epoch", epoch); break
model.load_state_dict(torch.load('best.pt'))
```

### 4.4 L1 正则（需手动加）

```python
l1_lambda = 1e-5
loss = loss_fn(logits, y)
l1 = sum(p.abs().sum() for p in model.parameters())
loss = loss + l1_lambda * l1   # 手动加 L1 惩罚
loss.backward()
```

## 五、正则化强度的选择

$\lambda$ 是超参数，靠验证集调。一般规律：

| $\lambda$ | 现象 | 适用 |
|-----------|------|------|
| 太大 | 欠拟合，训练损失也高 | — |
| 太小 | 过拟合，训练低/验证高 | — |
| 合适 | 训练略升，验证最低 | 最佳 |

**经验**：小数据集需要强正则（大 $\lambda$ + dropout）；大数据集正则可减弱。

## 七、直觉总结

```
过拟合: 模型把训练集的噪声也背了下来, 泛化差
正则化: 在损失里加一句"别太复杂"

  L2 (权重衰减): 大权重受罚 ⇒ 所有权重都小一点 (光滑)
  L1:           绝对值受罚 ⇒ 很多权重直接归零 (稀疏, 特征选择)
  Dropout:      随机删神经元 ⇒ 强迫冗余, 隐式集成
  早停:         用验证集控制训练时长，与 L2 有关联但通常不等价

数学根: 偏差-方差权衡; 泛函: 函数空间范数约束
```

**正则化 = 给"只顾拟合"的优化器装上刹车。** 数学是范数惩罚，工程是各种随机性。
