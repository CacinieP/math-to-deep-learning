# 大语言模型的缩放定律

> 大模型的能力随参数量 $N$、数据量 $D$、算力 $C$ 的增长遵循**平滑的幂律**：损失 $L = L_\infty + (N/N_0)^{-\alpha}$。这是一定模型、数据与算力范围内的**经验拟合**；统计学习和物理类比提供解释思路，尚不能把它当普适定理。理解缩放定律，才能理性预测"再投 10 倍算力能换多少能力"。

**难度**：[前沿]（需要幂律 + 对数 + 统计直觉）

## 一、纯数学：幂律与标度

### 1.1 幂律

$$y = a x^b \quad \Leftrightarrow \quad \log y = \log a + b \log x$$

**双对数图上是直线**。幂律在自然现象里 ubiquitous：地震（Gutenberg-Richter）、城市人口、单词频率（Zipf）。

### 1.2 神经网络的缩放定律（Kaplan 2020）

OpenAI 发现，自回归语言模型的测试损失随三个量各自呈幂律：

$$L(N) = \left(\frac{N_0}{N}\right)^{\alpha_N}, \quad L(D) = \left(\frac{D_0}{D}\right)^{\alpha_D}, \quad L(C) = \left(\frac{C_0}{C}\right)^{\alpha_C}$$

典型指数 $\alpha \approx 0.05 \sim 0.1$（缓慢但持续下降）。

**意义**：损失是**可预测的光滑函数**——投 10 倍算力，损失下降固定比例。

## 二、Chinchilla：算力的最优分配

### 2.1 Kaplan 的失误

Kaplan 计算最优为 $N \propto C^{0.73}$、$D \propto C^{0.27}$（参数增长远快于数据；其结论受学习率调度与未训至收敛影响），Chinchilla 修正为 $N$、$D$ 大致同比例增长（≈20 token/参数）。Kaplan 式分配导致许多大模型**参数过剩、数据不足**。

### 2.2 Chinchilla 的修正（Hoffmann 2022）

DeepMind 发现：固定算力 $C$ 时，最优的参数 $N^*$ 和数据 $D^*$ 应**等比例增长**：

$$N^* \propto C^{0.5}, \quad D^* \propto C^{0.5}$$

约 **20:1 的 token 数与参数比**是原论文实验设置下的经验量级，并非所有架构、数据质量、预算及推理成本目标下的普适最优常数。Chinchilla 用 700 亿参数 + 1.4 万亿 token，超过了 1750 亿参数的 GPT-3。

### 2.3 损失的联合公式

$$L(N, D) = E + \frac{A}{N^\alpha} + \frac{B}{D^\beta}$$

- $E$：经验拟合的渐近损失项；不能仅凭拟合就认定为真实熵
- $A/N^\alpha$：参数不足损失
- $B/D^\beta$：数据不足损失

在 $C\approx6ND$ 下，拉格朗日条件给出 $\alpha A/N^\alpha=\beta B/D^\beta$，进而 $N^*\propto C^{\beta/(\alpha+\beta)}$、$D^*\propto C^{\alpha/(\alpha+\beta)}$。只有指数相近时才近似平方根分配；还必须从数据拟合系数。

## 三、幂律的理论解释

### 3.1 临界现象类比（统计物理）

物理相变附近，序参量随温度呈幂律：$M \sim |T - T_c|^\beta$。**临界点处关联长度发散**，系统对扰动有幂律响应。

**类比猜想**：大模型接近某种"临界态"，loss 对算力呈幂律。这是启发性类比，尚不足以证明语言模型处于物理临界态或推出经验指数。

### 3.2 信息论视角

固定分词方式、数据分布和可用上下文时，期望交叉熵的理论下界是**条件熵**：

$$L_{\min}=H(\text{下一词}\mid\text{可用上下文}).$$

自然对数以 nat 计。对平稳过程，在条件上下文延伸到无限过去等适当极限下才得到熵率；有限上下文条件熵不必等于熵率。经验公式的 $E$ 是待拟合参数，可能包含模型族或实验范围限制，不能声称已经测得这个理论下界。

### 3.3 偏差-方差分解

参数不足 → 偏差大；数据不足 → 方差大。最优分配在偏差和方差间平衡——这是经典统计学习的现代回响。

## 四、涌现能力：相变的迹象

### 4.1 涌现现象

某些能力（少样本推理、数学解题）在小模型里几乎没有，参数越过某个阈值后**突然出现**——称为**涌现**。

### 4.2 相变解释

涌现酷似物理**相变**：水结冰、磁化等，在临界点性质突变。

**数学描述**：能力 $A$ 与规模 $N$ 的关系可能是**阶跃函数**而非幂律：

$$A(N) \approx \mathbf{1}[N > N_c]$$

$N_c$ 是临界规模。幂律描述损失（连续量），涌现描述能力（离散能力）。

### 4.3 争议

有研究（Schaeffer 2023）质疑：涌现可能只是**评估指标的非线性**（如用 exact-match 而非部分分数）。换指标后幂律重现。

## 五、工程实践：用缩放律做规划

### 5.1 拟合缩放律

```python
import numpy as np
from scipy.optimize import curve_fit

# 训练多个小模型, 记录 (N, D, loss)
def scaling_law(X, A, alpha, B, beta, E):
    N, D = X
    return E + A / N**alpha + B / D**beta

# 拟合
popt, _ = curve_fit(scaling_law, (Ns, Ds), losses)
# 用拟合结果外推: 投 10x 算力, 损失会到多少?
```

### 5.2 计算 Chinchilla 最优点

```python
# 给定算力 C, 求最优 N, D
# Chinchilla 算力估计 C ≈ 6ND (每参数每 token 前向+反向约 6 FLOPs)
# 最优 token/参数比 D ≈ 20N ⇒ C ≈ 6·N·20N = 120N²
def optimal_allocation(C):
    """采用固定 D/N=20 的教学估算，不是任意拟合缩放律的通用最优解。"""
    N = (C / 120) ** 0.5  # Chinchilla 算力估计 C≈6ND
    D = 20 * N
    return N, D
```

### 5.3 实践教训

- **数据常被低估**：Chinchilla 之前，大家堆参数不堆数据
- **幂律不会无限持续**：接近熵下界 $E$ 时饱和
- **数据质量需实测**：过滤和去重可能改善效率，不能保证固定的算力收益倍数

## 七、直觉总结

```
缩放定律: 损失随 N, D, C 平滑幂律下降 (双对数直线)
Chinchilla: 原实验下参数和数据近似同比增长（20:1 仅经验量级）
E: 拟合的渐近项；理论下界是给定上下文下的条件熵
涌现: 某些能力在临界规模"突然出现"(相变迹象, 有争议)
```

**缩放律在验证过的范围内帮助预测平均损失。** 单项能力、分布变化及远距离外推仍需单独验证。 数学是幂律，工程是算力分配的最优化。
