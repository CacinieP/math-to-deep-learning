# 正交基 → 残差与变换

> 正交基让向量能在不同表示间无损切换：$\mathbf{v} = \sum_i \langle \mathbf{v}, \mathbf{e}_i\rangle \mathbf{e}_i$。深度学习里，残差连接 $\mathbf{h}_{l+1} = \mathbf{h}_l + f_l(\mathbf{h}_l)$ 本质上是在做**恒等基 + 学到的修正**——网络学习相对恒等映射的修正。残差分支不必与输入正交，也不必处于更低维子空间。

**难度**：[进阶]（需要正交基 + 投影 + 残差网络经验）

## 一、纯数学版：正交基与投影

### 1.1 正交基的定义

内积空间 $V$ 中，一组基 $\{\mathbf{e}_i\}$ 若满足：

$$\langle \mathbf{e}_i, \mathbf{e}_j\rangle = \delta_{ij}$$

称为**标准正交基**（ONB）。

**例子**：
- $\mathbb{R}^n$ 的标准基 $\{\mathbf{e}_1, \ldots, \mathbf{e}_n\}$
- Fourier 基 $\{e^{inx}\}$（在周期 $2\pi$、内积带 $1/(2\pi)$ 的 $L^2$ 中）
- 标准归一化的 Haar 小波基、归一化后的 Legendre 多项式

> 📖 正交：[特征值与特征向量详解](https://github.com/CacinieP/Mathematics-Universe/blob/main/04-线性代数/05-特征值与特征向量/特征值与特征向量详解.md)

### 1.2 正交投影与展开

任何 $\mathbf{v} \in V$ 可唯一展开：

$$\mathbf{v} = \sum_i \langle \mathbf{v}, \mathbf{e}_i\rangle \mathbf{e}_i$$

**展开系数 = 投影长度**。正交基的价值：表示与重建都**最简单、最稳定**（数值不放大误差）。

### 1.3 正交变换保长度保内积

正交矩阵 $Q$（$Q^\top Q = I$）满足：

$$\|Q\mathbf{v}\| = \|\mathbf{v}\|, \quad \langle Q\mathbf{u}, Q\mathbf{v}\rangle = \langle \mathbf{u}, \mathbf{v}\rangle$$

**几何**：旋转、反射、置换——刚体变换，不改变距离。这在残差网络分析里极重要。

### 1.4 完备性与 Parseval 等式

若 $\{\mathbf{e}_i\}$ 完备（构成整个空间），则：

$$\|\mathbf{v}\|^2 = \sum_i |\langle \mathbf{v}, \mathbf{e}_i\rangle|^2 \quad \text{(Parseval)}$$

**能量守恒**：信号在时域和频域的能量相等。

## 二、残差连接：恒等基 + 修正

### 2.1 残差块的结构

ResNet 的核心模块：

$$\mathbf{h}_{l+1} = \mathbf{h}_l + f_l(\mathbf{h}_l)$$

输出 = **输入（恒等）** + **学到的残差 $f_l$**。

### 2.2 正交基视角：在恒等方向上做小扰动

把恒等映射 $\mathbf{h} \mapsto \mathbf{h}$ 看作"基方向"，$f_l(\mathbf{h})$ 看作"修正方向"：

$$\text{输出} = \underbrace{\mathbf{h}}_{\text{基(已知)}} + \underbrace{f_l(\mathbf{h})}_{\text{残差(要学)}}$$

**对比无残差**：$\mathbf{h}_{l+1} = g_l(\mathbf{h}_l)$ 要让 $g_l$ 同时学"保留信息"和"变换信息"，负担重。残差把"保留"交给恒等，让 $f_l$ 只学"变换"。

### 2.3 从优化视角：梯度的高速公路

反向传播时（链式法则）：

$$\frac{\partial L}{\partial \mathbf{h}_l} = \frac{\partial L}{\partial \mathbf{h}_{l+1}} \cdot \left(I + \frac{\partial f_l}{\partial \mathbf{h}_l}\right)$$

**关键项 $I$**：当残差分支雅可比很小时，单块梯度传播接近恒等。但两项可能相互抵消，多层也可能累积放大；残差不保证无损回流。

> 📖 链式法则：[01-梯度→反向传播](../轴线C-优化理论/01-梯度→反向传播.md)

### 2.4 残差 = 显式恒等映射

实验发现：移除残差的"加法"（只用 $f_l$），深网络立刻退化；加上后，即使上百层也能训练。**残差让恒等映射成为网络的"默认行为"**，学习只需修正。

## 三、正交性与网络稳定性的深层联系

### 3.1 正交初始化为何有效

若每层权重 $W_l$ 初始化为近似正交，则信号前向传播：

$$\|W_l \mathbf{h}\| \approx \|\mathbf{h}\|$$

**信号能量守恒**——既不爆炸也不消失。Xavier/He 初始化的数学根据则是让前向/反向信号**方差守恒**（正交初始化是另一条独立路线）。

> 📖 初始化与方差：[03-正态分布→Xavier-He初始化](../轴线B-概率模型/03-正态分布→Xavier-He初始化.md)

### 3.2 谱范数与 Lipschitz 约束

矩阵的谱范数 $\|W\|_2 = \sigma_{\max}(W)$（最大奇异值）。若 $\|W\|_2 \leq 1$，则 $W$ 是 Lipschitz 常数 $\leq 1$ 的映射——**非扩张映射**（严格压缩还要求常数 $<1$）。

**应用**：
- GAN 里谱归一化判别器（让 Lipschitz 有界，稳定训练）
- 深网络里限制每层谱范数，缓解梯度爆炸

### 3.3 正交权重机器学习研究

一些工作直接**约束权重正交**（$W^\top W = I$），对方形线性层保范数；加入激活或维度变化后并不保证信号完美传递。但实践上正交约束太强，牺牲表达力，多用于特定场景（RNN 缓解梯度消失）。

## 四、Transformer 里的正交与残差

### 4.1 残差是 Transformer 的骨架

现代 Transformer（GPT-2、LLaMA 等）普遍采用 **pre-norm** 残差结构：

$$\mathbf{h}_{l+1} = \mathbf{h}_l + \text{SubLayer}(\text{Norm}(\mathbf{h}_l))$$

（原始 Transformer 与 BERT 用的是 **post-norm**：$\mathbf{h}_{l+1} = \text{Norm}(\mathbf{h}_l + \text{SubLayer}(\mathbf{h}_l))$）

**子层**（注意力、FFN）都包在残差里。残差有助于典型深 Transformer 的优化，但并非所有可训练架构都必须使用残差。

### 4.2 Layer Norm 的标准化作用

LayerNorm 在每个 token 的指定特征维内标准化：仿射前均值为 0、方差为 $v/(v+\epsilon)$，随后乘可学习的 $\gamma$ 并加 $\beta$。它不做样本间的逐特征标准化或白化，也不保证梯度各方向均衡。

### 4.3 注意力残差 = 加权聚合 + 恒等路径

注意力聚合值向量（一般不是可逆基变换），残差保留恒等。两者结合是在恒等路径上叠加可学习变换，不施加正交或补空间约束。

## 五、工程实现层：PyTorch 残差与正交

### 5.1 残差块

```python
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim, dim), nn.ReLU(), nn.Linear(dim, dim)
        )
    def forward(self, x):
        return x + self.net(x)   # 恒等 + 残差

# 深层训练还需合适初始化、残差缩放和学习率
model = nn.Sequential(*[ResidualBlock(128) for _ in range(100)])
```

### 5.2 正交初始化

```python
import torch.nn.init as init

linear = nn.Linear(512, 512)
init.orthogonal_(linear.weight)    # 正交初始化权重
# 信号前向时能量近似守恒, 缓解深网络梯度问题
```

### 5.3 谱归一化（GAN 用）

```python
import torch.nn.utils.spectral_norm as sn

# 幂迭代估计 σ_max 后归一化；有限迭代有误差，不是严格 ‖W‖₂≤1 证书
discriminator = sn(nn.Linear(128, 1))
```

### 5.4 Transformer 层（残差 + Norm + Attention）

```python
class TransformerLayer(nn.Module):
    def __init__(self, d=512, h=8):
        super().__init__()
        self.attn = nn.MultiheadAttention(d, h, batch_first=True)
        self.norm1 = nn.LayerNorm(d)
        self.ffn = nn.Sequential(nn.Linear(d, d*4), nn.GELU(), nn.Linear(d*4, d))
        self.norm2 = nn.LayerNorm(d)
    def forward(self, x):
        normalized = self.norm1(x)
        attn_out, _ = self.attn(normalized, normalized, normalized, need_weights=False)
        x = x + attn_out   # 残差1: 注意力
        x = x + self.ffn(self.norm2(x))    # 残差2: FFN
        return x
```

## 七、直觉总结

```
正交基: 让表示最稳定, 信息无损切换
残差:    输出 = 输入(恒等基) + 修正(要学的)
         把"保留信息"交给恒等, 把"变换信息"交给网络
梯度:    残差提供 I 这条高速公路, 深网络才训得动

正交初始化: 信号前向能量守恒, 防爆炸/消失
谱归一化:   估计并归一化谱范数，线性层近似非扩张
```

**残差以恒等映射为参照学习增量。** 正交初始化是另一种控制线性层范数的方法，两者不构成正交投影的等价关系。
