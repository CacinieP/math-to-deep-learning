# KL 散度 → 信息瓶颈

> KL 散度衡量两个分布的差异：$D_{\text{KL}}(p\|q) = \sum p\log\frac{p}{q}$。在深度学习里，它是变分推断的核心（VAE 的损失项）、知识蒸馏的目标、信息瓶颈理论的基石——后者声称：好的表示应该**最大化与标签的信息，最小化与输入冗余信息**，整个过程用互信息（KL 的期望形式）刻画。

**难度**：[进阶]（需要 KL 散度 + 互信息 + 变分推断直觉）

## 一、纯数学版：从 KL 到互信息

### 1.1 KL 散度的性质回顾

$$D_{\text{KL}}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = \mathbb{E}_{x \sim p}\!\left[\log \frac{p(x)}{q(x)}\right]$$

- 非负：$D_{\text{KL}} \geq 0$，等号当 $p = q$（Gibbs 不等式）
- 非对称：$D_{\text{KL}}(p\|q) \neq D_{\text{KL}}(q\|p)$
- 凸性：对 $(p, q)$ 联合凸

> 📖 KL 散度：[01-熵→交叉熵损失](01-熵→交叉熵损失.md)

### 1.2 互信息 = KL 的期望形式

两个随机变量 $X, Y$ 的互信息：

$$I(X; Y) = D_{\text{KL}}(p_{X,Y} \| p_X \otimes p_Y) = \mathbb{E}_{X,Y}\!\left[\log \frac{p(X,Y)}{p(X)p(Y)}\right]$$

**直觉**：$I(X;Y)$ 度量"知道 $X$ 能减少多少关于 $Y$ 的不确定性"。等价于：

$$I(X; Y) = H(Y) - H(Y|X) = H(X) - H(X|Y)$$

- $X, Y$ 独立：$I = 0$
- 离散且熵有限时，$X = Y$ 有 $I=H(X)$；非原子的连续 $X=Y$ 通常有 $I(X;X)=+\infty$，不能代成微分熵。

### 1.3 数据处理不等

表示仅由输入生成时，应使用马尔可夫结构 $Y\to X\to Z$（即 $Y\perp Z\mid X$），则：

$$I(X; Y) \geq I(Z; Y)$$

**含义**：经过表示 $Z$ 后，关于标签 $Y$ 的信息**只会减少，不会增加**。好的表示要让这个减少**尽量小**——尽量保留预测标签所需的信息。

## 二、信息瓶颈理论（Tishby, Pereira & Bialek, 1999/2000）

### 2.1 核心目标

找一个编码分布 $p(z\mid x)$，同时满足（连续确定性表示的互信息可能无穷大，通常需加噪、量化或其他明确建模）：
1. **压缩**：$Z$ 尽量"忘记"输入 $X$ 的细节 → 最小化 $I(X; Z)$
2. **预测**：$Z$ 尽量保留预测 $Y$ 的信息 → 最大化 $I(Z; Y)$

形式化为约束优化：

$$\min_{Z} \underbrace{I(X; Z)}_{\text{压缩}} - \beta \underbrace{I(Z; Y)}_{\text{预测}}$$

$\beta$ 控制压缩与预测的权衡。

### 2.2 信息瓶颈的几何图示

```
X (输入, 高维)
 │
 │  压缩: 丢掉与 Y 无关的细节
 ▼
Z (表示)        I(X;Z) 小(压缩)
 │              I(Z;Y) 大(预测)
 │  保留预测信息
 ▼
Y (标签)
```

### 2.3 与交叉熵损失的关系

交叉熵是 $H(Y\mid Z)$ 的上界，最小化它可提升 $I(Z;Y)$ 的一个变分下界，不等于直接优化真实互信息。它也不显式约束 $I(X;Z)$。信息瓶颈额外要求压缩——这是一种**信息论正则化**，可能改善泛化，但效果取决于任务、表示族及权衡强度。

## 三、KL 散度在变分推断中的角色

### 3.1 VAE 的损失（ELBO）

变分自编码器假设隐变量 $\mathbf{z}$ 有先验 $p(\mathbf{z})$（通常标准正态），用神经网络学推断网络 $q_\phi(\mathbf{z}|x)$。最大化证据下界（ELBO）：

$$\mathcal{L}_{\text{ELBO}} = \underbrace{\mathbb{E}_{q}\!\left[\log p_\theta(x|\mathbf{z})\right]}_{\text{重建项}} - \underbrace{D_{\text{KL}}(q_\phi(\mathbf{z}|x) \| p(\mathbf{z}))}_{\text{KL 项}}$$

**KL 项的作用**：让推断网络的后验 $q_\phi$ 不要离先验 $p(\mathbf{z})$ 太远——它与信息压缩相关，但并不等于 $I(X;Z)$。对数据分布平均后有

$$\mathbb E_{p(x)}D_{\mathrm{KL}}(q(z\mid x)\|p(z))=I_q(X;Z)+D_{\mathrm{KL}}(q(z)\|p(z)).$$

因此既惩罚表示携带的输入信息，也惩罚聚合后验与先验的不匹配。

### 3.2 高斯情形的 KL 闭式解

若 $q = \mathcal{N}(\mu, \sigma^2)$，$p = \mathcal{N}(0, 1)$：

$$D_{\text{KL}}(q \| p) = \frac{1}{2}\left(\mu^2 + \sigma^2 - \log\sigma^2 - 1\right)$$

这就是 VAE 里 KL 项的具体形式。

## 四、知识蒸馏：KL 作为教学目标

### 4.1 软标签蒸馏

Teacher 模型输出软分布 $q^T$（带温度 $T$ 的 softmax）。Student 学：

$$\mathcal{L} = (1-\alpha) H(y,q^{S,1})+\alpha T^2D_{\text{KL}}(q^{T,T}\|q^{S,T})$$

$q^{S,1}$ 是温度 1 的学生分布；$q^{T,T},q^{S,T}$ 是同一温度 $T>0$ 的教师/学生分布，对应下方代码。**KL 项**传递完整软概率向量中的类间关系，熵标量本身不能携带类别排列信息。

### 4.2 软标签与硬标签的区别

软标签携带类别之间的关系，可能改善学生模型。对于固定教师，$D_{\rm KL}(q^T\|q^S)=H(q^T,q^S)-H(q^T)$，所以软标签 KL 与软标签交叉熵的学生梯度完全相同；收益并非来自 KL 相比同一软标签 CE 的优势。

## 五、工程实现层：PyTorch 实现

### 5.1 VAE 的 KL 项

```python
import torch

def vae_kl(mu, logvar):
    # q=N(μ,σ²), p=N(0,1) 的 KL 散度闭式解
    return -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp(), dim=1).mean()

# VAE 训练
mu, logvar = encoder(x)
z = mu + torch.randn_like(mu) * (0.5 * logvar).exp()  # 重参数化
recon = decoder(z)
loss = recon_loss(recon, x) + vae_kl(mu, logvar)
```

### 5.2 知识蒸馏

```python
import torch.nn.functional as F

def distillation_loss(student_logits, teacher_logits, labels, T=4, alpha=0.7):
    soft = F.kl_div(
        F.log_softmax(student_logits / T, dim=1),
        F.softmax(teacher_logits.detach() / T, dim=1),
        reduction='batchmean'
    ) * (T * T)
    hard = F.cross_entropy(student_logits, labels)
    return (1 - alpha) * hard + alpha * soft
```

### 5.3 互信息的神经估计（MINE）

Donsker–Varadhan 不等式作用于总体期望；有限 batch 的 log-mean-exp 有估计偏差，样本值不保证低于真实互信息。下面是目标的简化估计，未包含原 MINE 的移动平均梯度校正。

```python
# Donsker–Varadhan 下界：I(X;Z) ≥ E_joint[T] - log E_product[exp(T)]
# f 是可学习的判别网络, 区分联合分布与边缘乘积
def mine_loss(joint_scores, marginal_scores):
    import math
    joint_scores = joint_scores.reshape(-1)
    marginal_scores = marginal_scores.reshape(-1)
    logmeanexp = torch.logsumexp(marginal_scores, dim=0) - math.log(marginal_scores.numel())
    return -(joint_scores.mean() - logmeanexp)
```

## 六、信息瓶颈能解释什么

### 6.1 泛化的信息论界限

常见信息论泛化界涉及整个训练集与训练算法输出之间的互信息，不能直接替换成单样本 $I(X;Z)$。常量表示有 $I(X;Z)=0$，却可能无法预测标签；压缩必须同时保留任务信息，不能保证越压缩泛化越好。

### 6.2 深度学习训练两阶段（Tishby 假说）

经验观察：训练初期网络**快速降低训练误差**（拟合阶段），后期**压缩表示**（$I(X;Z)$ 下降，泛化提升）。这个"压缩阶段"是否真实存在仍有争议。

### 6.3 表示解耦

两两互信息为零只保证两两独立，不保证联合独立（如两个独立比特与它们的 XOR）。联合依赖可用 total correlation $D_{\mathrm{KL}}(q(z)\|\prod_jq(z_j))$ 度量。$\beta$-VAE 加大逐样本 KL 权重会同时影响信息率、聚合依赖和边缘匹配；独立坐标也不自动对应语义因素，且并非所有任务都要求独立表示。参见 [Locatello 等原论文](https://proceedings.mlr.press/v97/locatello19a.html)。

## 八、直觉总结

```
KL散度: 两个分布的差异(≥0, 越小越像)
互信息: 知道 X 能减少多少 Y 的不确定性

信息瓶颈: 好表示 = 少记输入(I(X;Z)小) + 多保标签(I(Z;Y)大)
         类比: 考试复习只记考点, 不抄整本书

VAE: KL 项把隐表示压向先验(信息瓶颈实例)
蒸馏: KL 让 student 模仿 teacher 的类间相似度
```

**KL 散度是深度学习里"约束分布形状"的通用工具。** 数学是信息论，工程是各种损失项的组合。
