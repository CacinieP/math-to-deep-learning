## 主要实质修复

- 优化：补回 Nesterov 更新中的动量；区分确定性 GD 与 SGD 收敛率及前提；修正偏差—方差分解中把随机测试标签当回归函数的问题；统一 MSE/NLL 对应先验尺度；澄清早停、Adam 二阶矩和 L2/AdamW 的适用边界。
- 线性代数：统一 PCA/线性自编码器样本按行的矩阵维度，说明潜在坐标不唯一；区分完整矩阵 SVD 与缺失评分矩阵分解；协同过滤不再将邻居缺失评分作为零加入预测；纠正 Frobenius 截断误差、矩阵指数交换的充分/必要条件。
- Neural ODE：非线性残差用函数递推/求和，不能伪写为矩阵连乘；补齐连续极限条件；修正伴随方程梯度方向和参数积分符号；训练循环清零梯度；加入可运行的小数据例子；限定连续伴随内存和数值梯度误差。
- BNN：补齐 imports 和 KL 方法、修复不存在的 weight_sigma/bias_sigma 属性；使用稳定 softplus；ELBO KL 按全数据集 N 而非每批大小缩放。MC Dropout 仅启用 dropout、冻结 BN 运行统计、拒绝 n_samples<2、异常时也恢复所有模块原始 train/eval 状态。修正贝叶斯线性回归批量边缘方差。削弱错误的不确定性与泛化“保证”。
- 反向传播：统一列梯度记号；手写矩阵乘法示例匹配二维输入；ReLU 在零点选择次梯度时仍乘上游梯度；数值梯度在同一参数点重算并采用 float64。softmax MSE 梯度包含耦合项，Brier score 不再被误说为非法分类损失。
- 梯度/谱：取消单层谱半径≈1、单层谱范数>1便必然爆炸，以及残差/LayerNorm“锁定谱”的错误保证；加入矩阵乘积反例、单块奇异值界与权重范数条件。谱范数估计处理零 Jacobian。区别近似低秩、核化、稀疏及精确 FlashAttention。
- 函数逼近：稠密不等于 Schauder 基；可测函数推广不等于一致逼近不连续函数；深度分离仅对特定函数族成立。Fourier/注意力、正交基/残差、注意力/软 K-means 保留启发性联系，删除错误数学等价、正交、补空间及外推保证。
- 信息论：明确 bit/nat；修正数据处理不等式的 Markov 链方向；InfoNCE 分母不可用 log N 替换，总候选数含正样本；不把有限负样本下界当等式；MINE 补上 logmeanexp 的样本数归一化；固定教师的软 CE 与 KL 学生梯度相同；蒸馏冻结教师；区分表示互信息与信息论泛化界。
- Diffusion：反向时钟 s 与递减原时间 t 明确区分；VP 极限要求累计噪声积分发散，有限 T 是近似；噪声/score 损失需匹配时间权重；DDPM 采样均值中的错误 sqrt(beta) 改为 beta；修复批量任意维度加噪和设备处理。
- RLHF/PPO：固定 RM 下是单策略正则化优化，势博弈不提供通用 PPO 收敛保证；奖励模型和参考策略不回传梯度；KL 逐样本计入 advantage；旧 logp detach；拆出 collect_rollout，ppo_step 允许复用固定 rollout，多轮更新的 ratio 与裁剪真正生效；原伪 PPO 示例改成正确 score-function 策略梯度。补充 beta 的奖励尺度与长度依赖，删除“beta 大即安全”和必然 reward hacking。
- 图模型/缩放律：明确无向非负权假设、GCN 推导不只是 K=1、一般 MPNN 不等于低通；缩放律恢复为经验规律，20 token/参数不是普适定律，给出一般指数下算力最优分配条件。
- 附录：同步公式、scalar 绝对值、API JVP/VJP、反向 SDE 时钟与误导反例。
