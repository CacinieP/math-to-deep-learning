## 独立问题登记

### 数学定义、公式及适用条件

- **DL-001** SVD 的正交因子可含反射，矩形 Σ 的几何解释不能一律称旋转。
- **DL-002** 低秩截断的秩是至多 k；仅在 k(m+n)<mn 时才节省矩阵存储。
- **DL-003** 点积最大化须固定范数，归一化/余弦相似度须排除零向量。
- **DL-004** 秩亏不等于投影，可逆不等于剪切；投影需要幂等，正交投影还需对称。
- **DL-005** 特征值为负或零时“只缩放不改变方向”需区分反向和零像；方差解释要求半正定。
- **DL-006** 一般特征分解、实对称正交分解与 SVD 不可混用；排序时 Vᵀ 应交换行并同步 Σ。
- **DL-007** 通用逼近的稠密函数族不必是数学基，必须指定函数空间、范数/收敛方式。
- **DL-008** 深度分离结论必须给函数族、网络约束与误差度量，不能无条件推广到所有波形或奇偶函数。
- **DL-009** 非零梯度的欧氏最陡方向是局部单位方向结论。
- **DL-010** 无约束梯度下降收敛条件不能直接套到任意有约束定义域。
- **DL-011** 二阶 Taylor 的三阶大 O 余项需要更强光滑性，通常要求 Hessian 局部 Lipschitz。
- **DL-012** Lagrange 单约束需要正则性；“等值面相切”还需目标梯度非零。修复同处断裂的 LaTeX \ne。
- **DL-013** 惩罚形式与硬约束形式的对应不是任意 λ/C 的无条件等价，说明解与强对偶条件。
- **DL-014** 傅里叶变换模平方在相应可积条件下是能量谱密度；不能直接混称平稳过程功率谱。
- **DL-015** Fourier/Legendre 标准正交基的内积与归一化常数需要指定。
- **DL-016** 标准化需有限正方差；全维白化需正定协方差，奇异时只能在有效子空间讨论。
- **DL-017** 归一化图拉普拉斯需处理孤立节点，连续非负算子写作 −Δ；Chebyshev 多项式定义域不同于逼近区间。
- **DL-018** 随机微分方程中的布朗增量说明时间间隔；OU 平稳高斯结论补 θ>0、σ>0。
- **DL-019** 流的雅可比连乘须在每层对应中间点求值，密度公式在完整逆映射处求值。
- **DL-020** 可逆连续流不能靠加深改变支撑的拓扑。

### 概率、信息论与损失解释

- **DL-021** 均匀密度补区间外为零；条件概率比值补分母为正。
- **DL-022** 期望区分离散求和与连续积分，补可积性与方差所需二阶矩条件。
- **DL-023** 把似然写成样本或标签乘积时补相应独立/条件独立假设。
- **DL-024** Gaussian/Laplace 的 MSE/MAE 对应限于固定噪声尺度并允许正常数因子与加法常数；损失并非全是 NLL。
- **DL-025** 自然对数的信息单位是 nat；理想实数码长不是逐符号精确整数前缀码长。
- **DL-026** Huber 对应 exp(−ρ) 型密度，不能当成 Gaussian 与 Laplace 混合密度。
- **DL-027** 单个 pinball/quantile 损失估计一个分位点，不自动产生预测区间。
- **DL-028** 贝叶斯线性预测方差依赖后验协方差与输入方向，不能由离训练样本的距离单独决定。
- **DL-029** 区分认知与偶然不确定性的例子；可重参数化的潜变量采样仍然是随机过程。
- **DL-030** VAE 负 ELBO 重建项需要 E_q；注明对角方差、单样本估计及 SSE 系数 1 对应解码方差 1/2。
- **DL-031** 离散 I(X;X)=H(X) 不能直接套到非原子连续 X。
- **DL-032** VAE 平均 KL 分解为互信息加聚合后验与先验的 KL，不等于互信息本身。
- **DL-033** 蒸馏保留类间关系靠完整概率向量，不靠熵这个标量；硬项 T=1、软项师生用同一 T。
- **DL-034** 两两独立不推出联合独立；total correlation 才对应联合分解。
- **DL-035** MINE 的总体变分下界不等于有限 batch 数值必为下界，注明教学梯度缺少论文的 EMA 修正。
- **DL-036** 多分类 1−H 未必非负，不能作通用熵置信权重；Focal Loss 不是 Shannon 熵加权。
- **DL-037** 经验缩放定律常数并非测得的真实熵；有限上下文条件熵与熵率极限不同。

### 优化、初始化与推导一致性

- **DL-038** SGD/mini-batch 使用随机梯度 g_t；全数据梯度应称 GD。
- **DL-039** AdaGrad 与 RMSProp 的 epsilon 放置与所示 PyTorch 实现对齐；AdaGrad 衰减到零需要累计平方梯度无界。
- **DL-040** Newton 逆 Hessian 需要可逆，作为局部二次模型最小化方向需要正定条件；CG 也需正定或处理负曲率。
- **DL-041** 存在零特征值不排除鞍点；同时有正负特征值的 Hessian 仍可判定鞍点。
- **DL-042** BFGS 保持正定要求 sᵀy>0；区别 BFGS 与有限记忆 LBFGS 的存储成本。
- **DL-043** K-FAC 是 Fisher 块期望的 Kronecker 近似，δ 指损失对预激活的导数；移除无来源的应用断言。
- **DL-044** 区分 Xavier 的预激活方差、近线性激活近似与 He 的 ReLU 激活二阶矩，统一正文、图、表和总结。
- **DL-045** Xavier 不把 logistic sigmoid 原点导数当成 1；fan_in/out 不等时前后要求只可折中。
- **DL-046** SiLU 非正齐次，不能将标准正态二阶矩 0.356 的倒数直接当成 He 类增益；改为尺度相关固定点。
- **DL-047** 中心差分需要约 2n 次目标求值；反传/HVP 复杂度以计算图为基准，修正自动微分组合方式。
- **DL-048** 列/行梯度、Jacobian 连乘顺序与偏置独立计算图统一，修正网络层数和参数数目示例。
- **DL-049** GAN 的 −log4+2JS 是最优判别器下的原始 minimax 值，非非饱和生成器损失。
- **DL-050** 对随机采样动作的环境回报不可直接普通反传，需要 score-function/相应估计；乘数更新截断旧图。
- **DL-051** 先验系数与正则系数对齐：Gaussian λ/2 L2、Laplace λ L1；L+λ||θ||² 的耦合 weight_decay 对应 2λ。

### 工程统计、谱与模型语义

- **DL-052** 自动微分给浮点计算图的导数，不代表任意精度的实数精确微分。
- **DL-053** 批间清梯度有 micro-batch 累积例外；冻结参数与 detach 中间输出的梯度路径不同。
- **DL-054** ReLU 零点需约定导数/次梯度，“死亡”也不是任何训练设置下永久不可恢复。
- **DL-055** float32 最大有限值约 3.4×10³⁸；梯度爆炸是数学尺度问题，可先于溢出出现。
- **DL-056** AMP 是操作级混合精度，裁剪前先 unscale，步骤前清梯度，并说明非有限梯度跳过更新。
- **DL-057** BN 训练归一化方差为 v/(v+epsilon)，仿射与推理运行统计进一步改变统计量；gamma/beta 不创造原始零方差。
- **DL-058** BN 小 batch 问题依赖归一化轴上的有效样本数；track_running_stats=False、空间轴与 GN 范围说明准确。
- **DL-059** LayerNorm 统计在单个样本/token 内，不能声称每个特征跨样本标准化为方差 1。
- **DL-060** 谱归一化的有限幂迭代是估计，不能宣称严格 Lipschitz≤1 证书。
- **DL-061** softmax 温度趋零时，并列最大项上是均匀极限，不一定唯一 argmax。
- **DL-062** 多头自注意力由同一个 X 投影成各头 Q/K/V；随机独立 Q/K 并无天然亮对角线。
- **DL-063** 注意力矩阵谱半径、特征值、奇异值与阈值数值秩不可混称；数值低秩也不等于权重集中。
- **DL-064** Linear Attention 基于核特征分解，不等同于一个通用低秩近似定义。
- **DL-065** 纯注意力坍缩/GCN 过平滑需连通性、混合等条件，置换注意力与多连通分量是边界。
- **DL-066** Neural ODE 伴随法不是求解器，区分固定/自适应步长与数值似然；矩阵指数极限补 Δt=1/L。
- **DL-067** DDPM 示例数组 t=0 对应数学的第一步 x₁，避免把有噪状态误叫 x₀。
- **DL-068** STFT 是固定窗口的滑动局部频谱，不自动提供多种窗口宽度。

### 可执行示例与 API 边界

- **DL-069** PCA 增加 n>=2、合法主成分数检查；全零总方差的解释率明确为 NaN。
- **DL-070** 矩阵分解梯度公式对齐观测掩码、观测数归一化及正则项。
- **DL-071** 自适应 ODE 步返回实际接受步长与建议下一步长两个值，防止调用者以错误时间推进。
- **DL-072** 遮罩注意力支持广播并拒绝整行全遮罩，避免 softmax 全 −inf 的 NaN。
- **DL-073** 手写 BatchNorm 使用有偏批方差归一化、无偏方差更新 running_var，与原生实现一致；训练单值明确报错。
- **DL-074** GCNLayer 禁用未出现在公式中的偏置，保持归一化邻接乘法的代码/公式一致。
- **DL-075** 加权交叉熵自定义 batch mean 与 PyTorch 默认 sum-of-weights mean 区分。
- **DL-076** KL API 指明方向及 batchmean；默认 mean 还除类别数。
- **DL-077** 类别有放回独立抽样需 multinomial replacement=True；默认无放回不能等同。
- **DL-078** Gumbel-Softmax 是连续松弛，hard straight-through 有偏，不能称原离散分布的精确可重参数化样本。
- **DL-079** PyTorch conv 是互相关；实对称谱分解优先 eigh，避免 API 表与数学对象混淆。
- **DL-080** 同一耦合分区反复堆叠会有一半变量始终不变，需交替/置换；组合 log_prob 覆盖各层 logdet。
- **DL-081** DPO 公式速查展开策略与参考策略的对数比差，避免隐含缩写方向混淆。

### 知识断言与类比边界

- **DL-082** Dropout 的变分解释有模型/近似条件；数据增强不自动严格等价于一个先验。
- **DL-083** 稀疏剪枝不等同于任意 spike-and-slab 后验推断。
- **DL-084** Word2Vec 不能简单等同于原始共现计数矩阵的精确分解。
- **DL-085** InfoNCE 的互信息下界要求负样本条件；SimCLR/CLIP 优化对比代理目标，不直接计算真实互信息。
- **DL-086** RLHF KL 比较策略与参考策略，目标包含 prompt 期望；不是“人类偏好分布与模型”KL。
- **DL-087** 压缩/互信息或 KL 正则不保证语义、不保证泛化、不保证消除 reward hacking；移除确定性保证。
- **DL-088** 无监督潜变量独立不保证可辨识的语义解耦。
- **DL-089** 固定加权多目标优化不自动形成多主体博弈或 Nash 均衡；均衡须给定主体、策略与收益。
- **DL-090** “无残差 Transformer 不可能训练”等无条件结论收窄为优化稳定性经验。
- **DL-091** 训练/验证曲线是过拟合线索非充分证明；相关/因果例子改为温度对冰淇淋销售与溺水的共同影响。
- **DL-092** MLP 的层状全连接描述不能当作所有神经网络的结构定义。

## 发布后补充：Wiki 中文章节锚点

实际 GitHub Wiki 页面会对自定义中文 `a[name]` 再作百分号编码，与原生 GFM API 的 HTML 片段行为不同。发布后浏览器检查发现，带中文 `#section-…` 的链接停留在页顶，不能仅把它判为验证器误报。

导出器现将原章节 ID 映射为 `section-` 加 SHA-256 的前 20 位十六进制字符；链接、插入的锚点与 manifest 共用 `anchor_name`，并在每页检测碰撞。新增 Unicode、已编码片段、目标一致性及碰撞回归；保留原数学正文与公式。发布流程再核验 Wiki 文件哈希、全量公式和正文，以及浏览器实际章节定位。

另：两库 `math-formulas.json` 的本地与 CI 全局排列顺序不同；完整记录的多重集合一致。在线验证按完整记录及重复次数比较清单，并仍逐页检查公式顺序，避免把文件系统遍历顺序当作内容变化。

全量正文对比还发现 Gollum 会把普通段落中的 `[[…]]` 矩阵文本当作 Wiki 链接，丢失外层括号。导出器仅在非代码、非数学正文将这类完整双括号表达式写为行内代码字面量；增加回归以保证公式、行内代码及代码块保持原样。实际 Wiki 会继续解析 HTML 实体，因此单靠实体转义仍会丢失括号；最终行内代码方案已经通过真实发布页的完整正文哈希对比。


## 发布后补充：GitHub 公式前端限制

实际浏览器发现，GitHub Wiki 会拒绝 `operatorname` 宏；原生 GFM API 生成 `math-renderer` 标签并不代表浏览器能成功渲染。本仓库正文共 15 处改为 `mathop`、`mathrm` 与 `nolimits` 的等价组合，保留算子间距和下标位置，源文件与两个阅读入口同步修正。

依据 [GitHub 当前公式前端代码](https://github.githubassets.com/assets/chunk-lazy-element-math-renderer-def98b14253cbdbc.js)，检查脚本复刻 15 个禁用宏的三种子串匹配，并核算导出后的花括号成本：每公式不得超过 1000、每页累计不得超过 2000。此策略在 2026-09-19 实际读取，GitHub 后续若变更仍需更新门禁。全量 MathJax 检查继续保留；GFM 标签、宏门禁与实际浏览器核验分别承担不同验证范围，不再将 GFM API 标签计数等同于前端成功渲染。
